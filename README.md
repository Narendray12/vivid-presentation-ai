
# 🌟 Vivid Presentation AI  

Vivid Presentation AI is a **next-gen AI-powered tool** that helps you **generate stunning, professional presentations** in minutes using **AI**. Just provide a topic, and the app will generate **slides with content** and a **well-structured presentation flow**, making it perfect for students, professionals, and teams.  

Built with **React**, **Node.js**, **TypeScript**, and **OpenAI GPT**, this project demonstrates the power of AI-driven automation for productivity.

---

## 🚀 Features  

- **AI-Powered Slide Generation** – Create entire presentation decks from just a single prompt.  
- **Topic-Based Content** – Generate structured slides based on your topic.  
- **Real-Time Preview** – Instantly preview your generated slides.  
- **Download Presentations** – Export your slides for sharing or offline editing.  
- **Modern UI** – Clean, responsive design using **TailwindCSS**.

## 📦 Installation & Setup  

Follow these steps to set up and run the project locally:

### 1. **Clone the Repository**
```bash
git clone https://github.com/Narendray12/vivid-presentation-ai.git
cd vivid-presentation-ai
```

### 2. **Install Dependencies**
```bash
npm install
```

### 3. **Configure Environment Variables**
Create a `.env` file in the root directory and add your OpenAI API key:
```
OPENAI_API_KEY=your_openai_api_key_here
DATABASE_URL=your_database_url_here
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=Clerk_public_key
CLERK_SECRET_KEY=Clerk_secret_key
```

> ⚠️ **Important:**  
> - Never commit your `.env` file.  
> - Use `.gitignore` to keep it secure.

### 4. **Run the Development Server**
```bash
npm run dev
```

Your app will now be live at:  
```
http://localhost:5173
```
